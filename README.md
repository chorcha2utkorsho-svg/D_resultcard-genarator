# ডি-লিকন মডেল একাডেমী - ডিজিটাল রেজাল্ট ও স্কুল ম্যানেজমেন্ট সিস্টেম
### D-Likon Model Academy - Digital Result Processing & School Management System

ডি-লিকন মডেল একাডেমীর (স্থাপিত: ২০১৮ ইং, দক্ষিণগাঁও, গণি মার্কেট, সনমানিয়া, কাপাসিয়া, গাজীপুর) প্রাতিষ্ঠানিক কার্যক্রম, স্বয়ংক্রিয় রেজাল্ট প্রসেসিং ও প্রোগ্রেস কার্ড প্রিন্ট করার সম্পূর্ণ ওয়েব অ্যাপ্লিকেশন।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **অফিসিয়াল ফরম্যাটে মার্কশিট ও প্রোগ্রেস কার্ড (Pixel-Perfect Marksheet)**:
   - স্কুলের নির্ধারিত প্যাটার্নে A4 পেপার উপযোগী প্রোগ্রেস রিপোর্ট।
   - প্রাতিষ্ঠানিক গ্রেডিং স্কেল টেবিল (A+, A, A-, B, C, D, F)।
   - বিষয়ভিত্তিক মোট নম্বর, প্রাপ্ত নম্বর, প্রাপ্ত নম্বরের ৮০%, মাসিক ২০%, মোট প্রাপ্ত নম্বর ও সর্বোচ্চ নম্বর।
   - উপস্থিতি দিবস, মোট নম্বর, জিপিএ, মেধাক্রম ও শিক্ষকের মন্তব্য।
   - শ্রেণি শিক্ষক, প্রধান শিক্ষক ও অভিভাবকের স্বাক্ষরের স্থান (ডিজিটাল স্বাক্ষর সাপোর্টসহ)।

2. **একক ও ব্যাচ রেজাল্ট প্রিন্ট (Batch & Single Printing)**:
   - একক শিক্ষার্থীর রেজাল্ট কার্ড প্রিন্ট।
   - একসাথে সম্পূর্ণ ক্লাসের সকল শিক্ষার্থীর রেজাল্ট কার্ড পৃথক পেজে এক ক্লিকে প্রিন্ট।
   - ল্যান্ডস্কেপ ওরিয়েন্টেশনে সম্পূর্ণ ক্লাসের **ট্যাবুল্যাশন শিট (Tabulation Sheet)** প্রিন্ট ও CSV ডাউনলোড।

3. **শ্রেণি অনুযায়ী ডায়নামিক বিষয় তালিকা**:
   - প্লে, নার্সারি, কেজি থেকে শুরু করে সকল শ্রেণির জন্য বিষয় ও পূর্ণমান স্বয়ংক্রিয়ভাবে পরিবর্তিত হয়।
   - নতুন বিষয় সংযোজন ও মানবণ্টন পরিবর্তনের সুবিধা।

4. **মার্ক এন্ট্রি ফরম (Mark Entry)**:
   - শ্রেণি, শাখা ও বিষয়ভিত্তিক দ্রুত নম্বর ইনপুট।
   - প্রাপ্ত নম্বর লিখলেই স্বয়ংক্রিয়ভাবে ৮০% ও ২০% হিসাব করে জিপিএ এবং গ্রেড তৈরি।

5. **বাল্ক শিক্ষার্থী ডাটা আপলোড (Excel / CSV)**:
   - এক্সেল বা সিএসভি থেকে সকল শ্রেণির শিক্ষার্থীর তথ্য (রোল, বাংলা নাম, ইংরেজি নাম, শাখা, মোবাইল নম্বর, রক্তের গ্রুপ) এক ক্লিকে আপলোড।

6. **সিলেবাস ও প্রশ্নপত্র প্রস্তুতকারক (Question Paper & Syllabus)**:
   - সৃজনশীল (ক, খ, গ, ঘ ও উদ্দীপক), বহুনির্বাচনী ও সংক্ষিপ্ত প্রশ্নপত্র তৈরি ও প্রিন্ট।
   - সাময়িক ও বার্ষিক পরীক্ষার সিলেবাস ও মানবণ্টন তৈরি।
   - ক্লাস নোট ও স্টাডি মেটেরিয়ালস তৈরি ও প্রিন্ট।

7. **ডাটাবেস ব্যাকআপ ও রিস্টোর**:
   - সম্পূর্ণ ডাটা ব্রাউজারে সংরক্ষিত থাকে।
   - ১-ক্লিকে সম্পূর্ণ ডাটাবেস `.json` ব্যাকআপ ডাউনলোড এবং রিস্টোর করার সুবিধা।

## 🚀 প্রযুক্তি স্ট্যাক (Tech Stack)

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS v4, Lucide Icons
- **Build Tool**: Vite
- **Print Engine**: CSS Paged Media `@media print`, `@page { size: A4 }`

## 💻 লোকাল কম্পিউটারে রান করার নিয়ম (How to Run Locally)

```bash
# ১. রিপোজিটরি ক্লোন করুন
git clone <YOUR_GITHUB_REPO_URL>

# ২. ডিরেক্টরিতে প্রবেশ করুন
cd d-likon-school-management

# ৩. ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ৪. ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev
```

ব্রাউজারে `http://localhost:3000` ওপেন করে অ্যাপটি ব্যবহার করুন।
